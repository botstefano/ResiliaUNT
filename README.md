# ResiliaUNT

Primera base funcional en construcción. Sistema web para el seguimiento de resiliencia y acompañamiento estudiantil de Ingeniería de Sistemas — UNT.

**Estado:** código inicial en preparación. La aplicación todavía no está conectada a un proyecto Supabase ni desplegada en Render.

Consulta `docs/IMPLEMENTACION.md` para conocer el modelo, la instalación y las limitaciones de esta versión.
